# Ventic Pro V11.16.4 — Customer account management + password reset

## Customer account editing permission
New permission:
- `customer.accounts.edit`

Default:
- SUPER_ADMIN: always allowed.
- ADMIN: enabled by default.
- CUSTOMER_SERVICE: not enabled by default; grant it from Users & Permissions when needed.

The customer management screen can:
- Edit customer name.
- Edit phone number.
- Enable/disable account.
- Set/change customer password (minimum 6 characters).
- Show order count, property count, invoice count, billed amount, due amount, and active sessions.
- Any sensitive change revokes existing customer sessions.
- Audit Log stores before/after metadata without storing plaintext passwords.

## Forgot password
Customer login now includes "نسيت كلمة المرور؟".

Flow:
1. Customer enters phone.
2. System generates a 6-digit code valid for 10 minutes.
3. WhatsApp is attempted first, then SMS fallback.
4. Maximum 5 wrong attempts.
5. New reset request cooldown: 60 seconds.
6. Successful reset revokes all old customer sessions.
7. OTP itself is never stored in Audit Log / Notification payload.

## Staging testing
Password reset staging code is OFF by default for security.

To show the reset code on the public staging page, explicitly add:
- `PASSWORD_RESET_STAGING_VISIBLE=true`

Remove it or set it to `false` before using real customer data.

Production messaging uses the same existing WhatsApp/SMS credentials, plus optional:
- `WHATSAPP_PASSWORD_RESET_TEMPLATE`
- `WHATSAPP_PASSWORD_RESET_TEMPLATE_LANGUAGE=ar`

## Database
Additive Prisma change only:
- New relation `Customer.passwordResets`
- New table `CustomerPasswordReset`

No existing customer/order/invoice records are deleted or changed.
