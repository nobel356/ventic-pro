## التركيب
1. فك ZIP.
2. انسخ **محتويات** فولدر `Ventic-Pro-V14C-Favicon-Hero-Fix-READY-COPY`
   إلى Root مشروع `ventic-pro`.
3. Replace / Merge.
4. GitHub Desktop.
5. Commit:
   `V14C - fix hero VP mark and favicon`
6. Push main.

## بعد Deploy

لو Chrome عرض الأيقونة القديمة بسبب الكاش:
- Ctrl + F5
- اقفل Tab الموقع وافتحه من جديد
- أو جرّب Incognito مرة واحدة

لا يوجد Migration ولا Env جديدة ولا أي Script تشغيل.
